# FitPro

A mobile-first fitness app UI built from the FitPro design — splash, onboarding,
home, workouts, workout player with timer, AI coach chat, progress charts, and
profile.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- lucide-react icons

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

## Screens

`/` splash → `/onboarding` → `/home` → `/workouts` → `/workouts/:id` →
`/workouts/:id/play` → `/coach` → `/progress` → `/profile`
